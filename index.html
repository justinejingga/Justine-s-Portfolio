My Contribution:

AI based PPE Detection In Work Area (Group Project)

This group project was inspired by news reports of accidents at construction sites. The website provides an interface for monitoring construction site safety using live camera or CCTV footage, as well as image uploads for object detection. The system is designed to identify construction workers and safety equipment, such as helmets and safety vests, to support safety monitoring.

My Contribution:
Developed and trained a Computer Vision model using a pretrained YOLO architecture and the provided dataset to detect construction workers and safety equipment. Worked on model training to enable automated object detection for construction site safety monitoring.

Repository link: https://github.com/priyahita/YOLO_For_ppe_detection

Breast Cancer Support and Detection Website (Group Project)

This group project involved developing a medical website focused on breast cancer awareness and support. The platform integrates several features, including appointment booking, an online pharmacy, a Computer Vision-based mammogram classification system, and a chatbot to help users learn more about breast cancer.

My Contribution:
Developed and trained a Computer Vision model using the ResNet18 architecture to classify breast mammogram images as benign or malignant. The model was integrated into the website to provide image-based classification as part of the platform's breast cancer support features.

Repository: https://github.com/tiffieszn/Breast-Cancer-Detector-mammograms-.git , https://github.com/priyahita/Website_CrCenter_Health-Website
